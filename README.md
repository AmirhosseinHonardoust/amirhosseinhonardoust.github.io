# honardoust.me

A clean, professional static portfolio website for Amirhossein Honardoust.

## Purpose

`honardoust.me` is designed as the main professional identity site:

- Data Scientist positioning
- selected featured projects
- concise skills and about sections
- links to GitHub, LinkedIn, and `honardoust.codes`
- SEO-friendly metadata
- responsive design
- light/dark theme toggle
- no build tools required

## How to edit

Main content lives in `index.html`.

Recommended edits before publishing:

1. Replace or add your preferred public email/contact method.
2. Add a real resume PDF at `assets/Amirhossein_Honardoust_Resume.pdf` if you want a resume button.
3. Add a real Open Graph image at `assets/og-image.png`.
4. Update featured projects if you want a different order.
5. Keep `honardoust.me` focused on the professional portfolio and use `honardoust.codes` for technical notes.

## Deploy with GitHub Pages

1. Create a new repository named something like `honardoust-me`.
2. Upload these files to the repository root.
3. Keep the `CNAME` file with:

```text
honardoust.me
```

4. Go to repository Settings → Pages.
5. Deploy from the main branch.
6. In your domain DNS, point `honardoust.me` to GitHub Pages.

## Deploy with Netlify

1. Drag this folder into Netlify.
2. Add the custom domain `honardoust.me`.
3. Configure DNS using Netlify instructions.

## Deploy with Vercel

1. Import the folder/repository.
2. Framework preset: Other.
3. Add the custom domain `honardoust.me`.

## Canonical strategy

Use `honardoust.me` as your main professional site.

Use `honardoust.codes` as a separate technical lab, not a duplicate of this site.
